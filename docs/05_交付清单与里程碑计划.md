# 05 交付清单与里程碑计划

## 1. 全量交付物清单

### A. 运行时组件
| # | 交付物 | 形态 | 说明 |
|---|---|---|---|
| A1 | **librtdbcore**（`rtdbcore.dll` / `librtdbcore.so`） | 动态库(+静态库可选) | L0~L3 全部：平台抽象/infra/存储/引擎。嵌入用户唯一依赖 |
| A2 | **rtdbd** | 守护进程/服务 | RPC 服务端+订阅推送+快照恢复+watchdog；支持 Windows 服务与 systemd 单元文件 |
| A3 | **rtdb_client** 动态库 + `rtdb_client.hpp/c.h` | 动态库 | 网络客户端：连接池/自动重连/角色切换/订阅回调 |
| A4 | RDB 同步插件框架 + MySQL 示例适配器 | 动态插件 | 接口头 `IRdbSyncAdapter.hpp`；Oracle/Sybase 等由使用方实现 |
| A5 | SQL 单表子集执行器（内嵌于 core，可裁剪编译开关） | 库内置 | SELECT/UPDATE/INSERT/DELETE + WHERE 比较逻辑 + ORDER BY/LIMIT |

## 4. 性能验收基线（单机 i7/32G 参考值）
| 场景 | 指标 |
|---|---|
| 嵌入单行 upsert(主键) | P99 ≤ 10 μs（fsync=per_second） |
| RecordBlock 批量 upsert | ≥ 1,000,000 行/s（8 列混合类型） |
| 主键点查 | P99 ≤ 3 μs；范围扫描 10 万行 ≤ 30 ms |
| WAL 重放恢复 | 1 GB 变更日志重放 ≤ 60 s |
| 网络批量吞吐(单连接千兆网) | ≥ 200,000 行/s |
| 订阅端到端延迟 | 本机 ≤ 1 ms；跨机 P99 ≤ 50 ms |
