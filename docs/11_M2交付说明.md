## 1. M2 目标回顾

| 项 | 内容 |
|---|---|
| 周期 | 约 3 周（W1~W3；规划 2026-10，本机收敛 2026-10-17） |
| 范围 | NativeApi 收敛、CAbi、RecordBlock 批量、Result 体系（docs/05 §3） |
| 出口标准 | ① 《04》示例程序原样跑通；② bench 嵌入模式达标（docs/05 §4） |
| 覆盖率门禁 | 维持 M1 水平：engine/ 与 storage/ ≥ 85%（全局 ≥ 80%） |

M2 的定位是"接口"：M1 交付了引擎能力但公共面是演进式的，M2 以 docs/04 为基准**收敛**
公共 API——伞头、规范命名、Row/Upsert 便利面、列式批量入口、Result 便利宏，以及
**冻结符号的 C ABI**（跨语言绑定基座）。引擎内核语义不变（WAL/组提交/恢复/快照全部
沿用，RecordBlock 走同一条组提交管线）。

## 2. 交付清单与完成情况

### 2.1 运行时代码

| 组件 | 文件 | 提供的能力 |
|---|---|---|
| 伞头 | `include/rtdb/rtdb.hpp` | C++ 公共面一键包含（C 头单独发行） |
| 跨度视图 | `include/rtdb/span.hpp` | C++17 轻量只读 Span（指针+长度；vector/C 数组隐式构造；禁绑临时容器） |
| 选项 | `include/rtdb/options.hpp` | 字段对齐 docs/04：`instance/path/role/wal_fsync`（+`initial_size_bytes`） |
| 表定义 | `include/rtdb/table_def.hpp` | `TableDef` 增 `primary_key/secondary(IndexDef)/max_rows_hint`；双闸门校验 |
| 列值/行 | `include/rtdb/column_value.hpp` | 六枚隐式构造（int64/double/bool/const char*/string_view/string）+ `Row` |
| 表句柄 | `include/rtdb/table_handle.hpp` | 持非拥有 `Engine*`；const 成员 `Upsert/Get/Delete` |
| Result | `include/rtdb/result.hpp` | `operator*`/`operator->`；`RTDB_CHECK`/`RTDB_ASSIGN_OR_MOVE`（Err 返回契约） |
| 列式批 | `include/rtdb/record_block.hpp`（header-only） | `BlockColumn/RecordBlockView/RecordBlock`（链式 AppendColumn、空值掩码、构建期校验、非法块空视图） |
| 引擎门面 | `src/engine.cpp` | `Upsert`（合并/插入两路径）、`UpsertBatch`（三阶段原子块，整行覆盖）；共享列元数据助手；块暂存缓冲跨批复用 |
| **C ABI 头** | `include/rtdb/rtdb_cabi.h` | 自包含纯 C 头：错误码/角色/档位/类型常量镜像、7 个结构体、14 个符号、`RTDB_ABI_VER=1`（M2 冻结值；M3 起 =2，见下方现态注记） |
| **C ABI 实现** | `src/api/c_abi.cpp` | 薄封装（参数解码→引擎→错误码映射）、边界无异常、C 所有权语义（free_row/free_rows） |
| 版本 | `include/rtdb/version.hpp` | `RTDB_ABI_VERSION 0 → 1`（M2 符号集冻结）；M3 起 `=2`（订阅/会话符号族） |

> **现态（M3 起，2026-10-22）**：`RTDB_ABI_VER` 与 `RTDB_ABI_VERSION` 已统一为
> **2**（M3 订阅/会话符号族追加，v1 既有符号语义不变），`src/api/c_abi.cpp` 以
> `static_assert(RTDB_ABI_VERSION == RTDB_ABI_VER, ...)` 做单一真源校验。上表为
> M2 冻结时的历史快照（docs/14 §11.1 P2）；M4 保持 **v2 冻结**、不新增 C ABI
> 符号（docs/16 D6/D11）。

C ABI v1 符号集（`rtdb_abi_` 前缀，详见头文件）：

```
version / open / close / committed_seq / create_table / open_table / drop_table /
close_table / insert / get / scan / upsert_block / free_row / free_rows
```

### 3.2 规范-落地收敛记录（docs/04 → 实现）

| # | 规范表述 | 落定形态 | 原因 |
|---|---|---|---|
| 1 | `TableDef.columns` 为 `std::span<const ColumnDef>` | `std::vector<ColumnDef>` | 113 存量用例均 push_back 形态；span 化迁移成本高于收益 |
| 2 | 变长列 `{"desc", String, 64}`（长度上限） | 变长列 `len` 必须为 0 | M1 语义；单列长度上限约束列入复评清单 |
| 3 | `max_rows_hint = 1000000` | 示例取 2048（可行上限 ~910/8 列约 72B） | M1 行数据区 64KB 单块约束；段目录化复评（§7） |
| 4 | 指示器初始化（`.instance=…`） | 聚合赋值形态 | 库标准 C++17，MSVC 指示器初始化需 C++20 |
| 5 | `rtdb_abi_open(instance, path, role, void** h)` | 增 `wal_fsync` 参数 + 不透明 `rtdb_engine*` | 打开时确定组提交档位；C 侧免强制转换 |
| 6 | 订阅族（`Subscribe/ChangeCursor`、`rtdb_abi_subscribe`） | 未实现，注释标注 | 归 M3 会话层（docs/05 §3） |

### 3.3 顺延项复评结论（docs/09 §8 T6 输入，2026-10-17）

| 项 | 复评结论 | 依据 |
|---|---|---|
| **段目录化**（行槽 >8192 / 百万级 `max_rows_hint`） | **维持顺延**（M3 或数据量驱动时立项） | M2 实测 8 列约 72B/行可行 row_cap ≈ 910；512 行块稳态 1.2M 行/s 已达标，真实数据量未出现。工程量：行寻址/版本数组/墓碑位图布局重写 + table_store/wal 重放/快照拷贝牵连，估 2 周+ |
| **doublewrite**（机器断电页乱序） | **维持顺延** | D1 已拍板（always 档兑现零丢失、断电承诺分级）；无新增需求。bench 显示 always 档 P99 272μs，远离 10μs 热路径预算，双写会进一步推高 |
| **compact**（行槽/变长块回收） | **维持顺延** | RecordBlock 500k 次覆盖更新的 var 池实测有界（更新路径回收旧块）；唯一泄漏点是重放不回收变长块（M1 既定，有界）。M2 未引入新泄漏面 |

### 5.2 混沌矩阵（四类场景 × 11 注入点）

`scripts/chaos_m1.sh 100`（MSVC Release 二进制，2026-10-17 实测，证据日志
`/tmp/rtdb_chaos/chaos_m1_20261017_171401.log`）：

```
rounds=100 injected_hits=88 load_completed=12 child_errors=0
verify_pass=100 verify_fail=0
RESULT: PASS（数据零丢失/无半截记录/committed_seq 一致/恢复幂等/崩溃后可写）
```

- **88 轮真实命中注入**（子进程退出码 9）+ 12 轮无注入对照（完整负载 → 全量数据零丢失）；
- **11 个注入点全覆盖**：`block.commit.before`×14、`wal.batch.wal_mid`×12、
  `block.apply.mid`×9、`snapshot.before_copy`×9、`wal.batch.mid`×8、
  `secidx.before_link`×8、`wal.apply.mid`×7、`wal.commit.before`×6、
  `alter.before_link`×6、`wal.append.mid`×5、`wal.insert.before`×4；
- **四类场景分布**：insert×24、block×24、batch×21、secidx×13、snapshot×12、alter×6；
- **持久化档位**：always×37 / never×33 / per_second×30；
- 每轮验证五项不变量：committed_seq 一致、无半截记录、数据零丢失（前缀完整）、
  恢复幂等、崩溃后可写；另附场景 schema 自洽与快照副本可挂载核对。

## 7. 已知边界与 M3 衔接

| 边界 | 说明 | 归属 |
|---|---|---|
| 订阅族（embedded Subscribe/ChangeCursor） | WalRing+seq 基座已就绪，只差会话层；docs/04 §3 示例订阅段与 `rtdb_abi_subscribe` 随 M3 追加 | M3 |
| 段目录化（行槽 >8192） | 8 列混合可行 row_cap ≈ 910（64KB 行数据区）；百万级容量待数据量驱动 | M3+ |
| doublewrite / compact | 复评维持顺延（§3.3） | M3+ |
| 复合主键 / 任意位置主键 | `primary_key` 仅支持列 0 单列（多列/非列 0 → kUnsupported） | 段目录化同批 |
| 变长列长度上限（docs/04 `String,64`） | 未支持，`len` 必须为 0 | 复评清单 |
| C ABI 订阅/异步 | v1 冻结为同步 CRUD/批/扫面；订阅族随 M3 在 v2 追加（只增符号，不改旧符号） | M3 |
| RecordBlock 载荷类型 | 仅 int64/double/string_view 三类（覆盖整数类/bool/时间戳/浮点/变长列） | 按需扩展（只增 AppendColumn 重载） |
| Ubuntu 实机验证 | GCC（MinGW）已验证；Ubuntu 与 CI 复跑 | CI |
