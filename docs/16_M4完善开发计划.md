## 4. 关键设计决策（D1~D12）

### D1 Authz = 部署式用户表 + 表级权限位

- 配置/CLI 扩展：`user = <name> <64hex> [perm]`；`perm` = `admin` / `ddl` / `r` /
  `w` / `rw`，后接表名列表（`*` 通配），如 `user = etl <64hex> rw meters,alarms`；
- **向后兼容**：M3 的 `--user name=digest`（无 perm）解析为 **admin**（保持
  docs/15 测试手册、双机脚本、既有单测不变），启动日志提示 legacy 默认 admin；
- 权限维度：`admin`（ADMIN 面）、`ddl`（建/删表、加列、二级索引）、表级 `r/w`；
  列级位图预留（M5 启用）；用户表 Start 时冻结、不支持热更新（M5）；
- 与 P1-7 衔接：握手/空闲超时、AUTH 失败退避/限次为既有基础设施，Authz 只加
  授权判定与审计计数，不重复造轮子。

### D2 权限门在 Dispatch 前置 + 新错误码 + 审计计数

- `Dispatch` 会话校验后按 func 查权限：DDL→`ddl`；EXEC_BATCH/BLOCK→表级 `w`；
  SCAN/SCAN_PAGE→`r`；SUBSCRIBE/FETCH_DELTA→订阅表 `r`；PING/AUTHZ_ME→免验；
  ADMIN→`admin`；
- 拒绝统一 `kPermissionDenied = 503`（err.hpp 5xx 尾部追加，协议宏同步
  `RTDB_E_PERMISSION_DENIED 503`），累加 `authz_denied_total`；可选
  `rtdbd --log-denied` 输出一行 `[authz] user=... func=... table=...`（默认关）；
- AUTH 响应**保持不变**（session id + ttl）→ M3 客户端兼容；新增
  `RTDB_PF_AUTHZ_ME 41` 返回自身用户/权限摘要（协议只增）。

### D3 PerfCounters = 进程内原子计数 + ADMIN/STATS 面

- 实现：`Server::Impl` 内 `std::atomic<uint64_t>` 组（host 内存，无 shm 布局变更），
  会话/订阅/引擎路径轻量打点（无锁、无分配）；引擎侧补充计数器（环回收次数、
  保留水位、slot 复用数、ScanLimited 截断次数）经 `Engine` 暴露只读快照；
- 指标 v1（C4 逐项口径）：uptime、requests_total、errors_total{frame,payload,
  protocol,auth,authz}、auth_ok/fail、auth_timeout_closed、sessions_current/total、
  accepted/rejected_full、sub_deliveries/sub_overflows、writes_total、batch_ops、
  scan_calls/rows/limited_truncated、wal_appended_bytes/records、
  wal_backlog_bytes、wal_reclaim_count、wal_retained_seq、slot_reuse_count、
  flush_count/flush_us_total、poisoned、committed/checkpoint/flushed/heartbeat；
- 暴露：`RTDB_PF_ADMIN 40`（子操作 `STATS=1`、`AUTHZ_SHOW=2`），载荷
  `[u16 ver][u32 n][(u16 key)(u64 value)]...`（key 常量表，版本化可增）；
  `rtdbctl status` 表格/`--json`。

### D4 SQL 语法子集冻结（v1）

```
select_stmt := SELECT select_list FROM table [WHERE expr] [ORDER BY col [ASC|DESC][,...]] [LIMIT n [OFFSET m]]
select_list := '*' | col [AS alias] [, ...]
insert_stmt := INSERT INTO table '(' col [,...] ')' VALUES '(' literal [,...] ')' [, ...]
update_stmt := UPDATE table SET col = literal|expr [, ...] [WHERE expr]
delete_stmt := DELETE FROM table [WHERE expr]
expr        := expr AND expr | expr OR expr | NOT expr | '(' expr ')' | operand
operand     := col op literal | col IS [NOT] NULL
op          := '=' | '<>' | '!=' | '<' | '<=' | '>' | '>='
literal     := 整数 | 浮点 | 字符串（单引号，'' 转义） | TRUE/FALSE | NULL
```

- 关键字大小写不敏感；标识符大小写敏感；单条语句一次执行（多语句
  `kUnsupported`）；子集外（JOIN/子查询/聚合等）明确 `kUnsupported`；
- 语法错误新增 `kSqlSyntax = 307`（3xx 尾部追加，`ErrorMessage` 带简短说明）；
- 解析器 `src/sql/` 手写递归下降（零三方依赖），AST 独立可测 + fuzz 目标。

### D5 SQL 执行语义（复用 M3 加固后的引擎能力）

- **SELECT**：优先主键等值/范围下推，否则全表扫；使用 **`Engine::ScanLimited`**
  分页读取（避免一次性物化全表，O(logN+page_rows)）；内存过滤/排序/`LIMIT`；
  预算 `RTDB_SQL_MAX_ROWS`（默认 100k）与响应载荷上限；
- **INSERT**：单行 `Insert`；多行 `ExecuteBatch`（批原子）；行槽复用由存储层
  自动处理（P0-3），SQL 层不感知；
- **UPDATE/DELETE**：先按 WHERE 解析目标主键（ScanLimited 分页收集），再
  `ExecuteBatch` 批原子执行；非主键 WHERE 受 `RTDB_SQL_MAX_ROWS` 限制并文档说明；
- **事务语义**：单语句原子（多行 INSERT/UPDATE/DELETE 批内原子，零副作用失败），
  **不提供**跨语句事务（M5）；UPDATE 复用 `StageUpdate` 就地更新语义（含 WAL/索引）；
- **结果**：`SqlResult`（列元数据 + 行集 + affected_rows + last_seq）。

### D6 SQL 交付面 = 内嵌 C++ API（M4 不扩 C ABI）

- C++：`include/rtdb/sql.hpp` + `Engine::ExecuteSql(std::string_view)`（或独立
  `rtdb::Sql::Execute`），返回 `Result<SqlResult>`；
- **C ABI 维持 v2 冻结**：M4 不新增 C ABI 符号（SQL C ABI 需 v3，归 M5）；避免
  再次 ABI 版本漂移与跨语言绑定返工；
- 网络 SQL 面不做；`rtdbctl` 不提供 SQL 命令（避免网络面暴露 SQL）。

### D7 编译开关与目录

- CMake：`option(RTDB_BUILD_SQL "Build embedded SQL subset" ON)`；OFF 时
  `src/sql/` 不编译、`sql.hpp` 不导出符号（可裁剪，docs/05 A5）；测试随开关条件；
- 目录：`src/sql/{ast.hpp,lexer.cpp,parser.cpp,exec.cpp}`、`include/rtdb/sql.hpp`、
  `tests/unit/test_sql.cpp`、`examples/sql_demo`（可选）。

### D8 migrate_from_psrtdb 设计

- CLI：`--source <老映像> --mapping <json> --target <新映像> [--dry-run] [--limit N]
  [--report <json>]`；
- `mapping.json`：表映射（新旧表名、列名/类型、主键列、可空、变长列、二级索引）
  + 转换规则（缺列默认、时间戳单位）；未知列/类型不匹配明确报错；
- 路径：只读打开源映像 → `IPsrImageAdapter`（表列举/行游标/字段读取；真实
  PSRtdb 适配器 + fixture 适配器）→ 新实例 `CreateTable`（按 `wal_ring_kb` 预算
  建映像）→ 分块 `UpsertBatch`（尊重 WAL 批预算）→ `CreateSnapshot`/flush；
- 校验报告：每表行数、主键集合校验和、抽样字段逐值比对、committed/checkpoint
  水位、耗时；`--dry-run` 仅解析 + 行数预估；
- 样例老映像：`--make-fixture` 生成同构夹具；验收以 fixture + 抽样比对为准
  （真实老映像不可得时记录为已知限制，适配器接口保持可替换）。

### D9 rtdbctl 范围

`status`（PING + ADMIN/STATS，表格/`--json`）、`ddl create|drop|describe`（TableDef
JSON）、`import|export`（CSV/JSON，按批预算分片）、`subscribe`（订阅打印，seq
有序）、`authz show|check`（AUTHZ_ME + STATS，按表检查 r/w）。连接/鉴权参数与
`bench_net` 一致（`--host/--port/--user/--password/--salt`）；无交互式 REPL、
无 SQL 命令（D6）。

### D11 兼容与版本纪律

- 协议仍为 **v1，数字只增不改**：新增 func 40/41、错误码 503/307；既有
  func/payload/AUTH 响应不变；
- **C ABI v2 冻结**：M4 只使用/测试，不新增符号、不改既有签名；`RTDB_ABI_VERSION`
  与 `RTDB_ABI_VER` 的 `static_assert` 保持单一真源；
- shm 布局不变（无 `kShmFormatVersion` 升级；PerfCounters 走 host+RPC）；
- M3↔M4 双向兼容：旧客户端连新服务端未用新面时行为不变（legacy 用户默认 admin）；
  新客户端连 M3 服务端时新 func 返回 `kNotImplemented`；
- 版本串：M4 收口时 `RTDB_VERSION_MINOR` 0→1、`kVersionString` → `0.2.0`；
  ABI 版本保持 2。

### D12 M4 技术债/顺延决策矩阵

| 项 | M4 | 理由/去向 |
|---|---|---|
