## 1. 里程碑回顾

M4 目标是把 M3 的「可用服务」补成「可交付产品」：SQL 单表子集、表级权限与审计、指标面、运维 CLI、老系统迁移工具、以及 C1~C5 文档矩阵。W1~W3 的编码与验证记录见 [docs/16 §11~§13](16_M4完善开发计划.md)；本文只给**交付清单、验收状态、已知限制与收口条件**。

M3 已于 2026-11-09 按方案 A 关闭（tag `m3`）：功能出口项全部达标，跨机吞吐 103,351 行/s（桥接虚拟网络 + A 机 100 Mbps 物理链路）记为已知限制，性能专项归 M5；200k 行/s 明确为裸机千兆理想环境目标。

## 6. 已知限制（不得在交付说明中隐去）

1. **跨机吞吐性能**：本次虚拟化/100 Mbps 环境下 103,351 行/s，未达 200k（裸机千兆理想环境目标）；性能专项归 M5（排查清单见 docs/14 §5.2），不以调整验收参数凑数。
2. **真实 PSRtdb 二进制格式不可得**：迁移工具默认使用自描述同构 fixture 适配器，报告 `note` 字段明确记录；`IPsrImageAdapter` 保持可替换，接真实老映像需另实现并补 fixture 比对。
3. **协议安全边界**：明文 + 摘要口令、无 TLS，仅受信内网（docs/14 §8.3）；TLS/压缩/主动推送/多写者仲裁归 M5。
4. **SQL 范围**：仅内嵌单表子集，无网络 SQL 面、无 JOIN/子查询/聚合/优化器，子集外返回 `kUnsupported`；不提供跨语句事务（docs/16 D4/D5/D6）。
5. **迁移/数据面边界**：跨批导入无法全局原子（中途失败留下已成功前缀批，命令会明确打印已写入行数并提示用 `export` 核对）；`bytes` 列按 UTF-8 文本近似；NaN/Inf 不保证严格 JSON 往返。
6. **阶段性内核边界**：单表行数据 ≤64KB、主键限整数类、WAL 分段环/完整 compact/MVCC/表级 RWLock/跨进程游标登记等归 M5（docs/14 §11.2、docs/16 §3）。
7. **兼容测试口径**：`test_compat.cpp` 的「旧服务端」为协议层模拟（真实 M3 二进制不可得），「旧客户端」为同进程内只走 M3-W4 C ABI 旧面；仅验证降级路径与 ABI 冻结，非真实跨版本二进制互操作。
8. **版本纪律与口径统一**：docs/16 D11 原文「MINOR 0→1、`kVersionString`→0.2.0」为笔误（0.1.0 时 MINOR 已是 1），2026-11-09 已把 `RTDB_VERSION_MINOR` 置 2 与字符串对齐，C ABI v2 / shm v2 不变。2026-11-10 另关闭两处历史不一致：`RTDB_PROTO_DEFAULT_PORT` 由 7878 统一为 5599（仓内原无引用）；`writer_heartbeat_ns` 注释与实现统一为 "Unix 纪元纳秒 / system_clock 墙钟"，并在 `RefreshWriterHeartbeat()` 用 `duration_cast<nanoseconds>` 显式换算，消除 MSVC 100ns tick 与 libstdc++ 1ns 的单位差异。两项均已同步 C1/C3。

## 8. 复现命令速查

```bash
# 构建（免 GoogleTest / 免外网，适用于部署验证）
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DRTDB_BUILD_TESTS=OFF
cmake --build build -j

# 完整测试（需 GoogleTest；可用 -DFETCHCONTENT_SOURCE_DIR_GOOGLETEST=<本地源码> 离线）
cmake -S . -B build_test -DCMAKE_BUILD_TYPE=Release -DRTDB_BUILD_TESTS=ON
cmake --build build_test -j && (cd build_test && ctest --output-on-failure)

# 演练（产物路径可用 RTDB_TEST_BIN / RTDBD_BIN / RTDBCTL_BIN 覆盖）
scripts/chaos_m4.sh 100
scripts/demo_alter.sh
scripts/ops_drill.sh

# 迁移冒烟
build/migrate_from_psrtdb --make-fixture fixture.json
build/migrate_from_psrtdb --source fixture.json --mapping mapping.json \
  --target target.rtdb --dry-run
build/migrate_from_psrtdb --source fixture.json --mapping mapping.json \
  --target target.rtdb --batch 512 --report report.json
```

版本与兼容校验：`include/rtdb/version.hpp`（0.2.0 / ABI v2 / shm v2）、`include/rtdb/rtdb_cabi.h`（`RTDB_ABI_VER=2`）、`tests/unit/test_compat.cpp`（编译期 + 运行期单一真源校验）。
